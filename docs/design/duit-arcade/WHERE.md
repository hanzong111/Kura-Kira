# DUIT Co-op Arcade pack: where things live

The runtime files (`assets/`, `css/`, `licenses/`) are in `dashboard/web/duit/` and are served by the
dashboard. This folder keeps the rest of the pack: the handoff, the reference mockup, the source art, the
export tools and the examples. To open `preview.html` or `examples/asset-gallery.html` here, copy
`dashboard/web/duit/assets` and `dashboard/web/duit/css` next to them first.
