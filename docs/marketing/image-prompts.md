# Kura-Kira image prompts (for ChatGPT image generation)

How to use these:

1. Run **prompt 1** first and pick the turtle you like. Save that image: it's the **mascot sheet**.
2. For every later prompt, **attach the mascot sheet** and paste the prompt. The prompts tell GPT to copy it exactly,
   which keeps the turtle the same in every post.
3. Each prompt already includes the style block below, so you can paste one prompt on its own.
4. Check every word of text in the result. If a word is misspelled, reply "fix the text: it must say exactly …".
5. Keep text short in images. Put longer copy in the post caption instead.

Sizes: Instagram/Threads feed **1080 × 1350 (4:5)**, square **1080 × 1080**, Stories/TikTok/Reels covers
**1080 × 1920 (9:16)**.

## Style block (already inside every prompt)

```
STYLE: crisp pixel art, like a cozy 16-bit game. Visible square pixels, no anti-aliasing, no blur, no gradients
except simple dithering, flat colours, hard 4px drop shadows, square corners. Palette only: plum night #211B32
(background), cream #F7EDCF and #FFF7E3 (panels, text), coral #F26F73, teal #62B6BB, leaf green #5F9E71, warm
yellow #F6CB45, red #E85167, soft blue #77A9C0. Headings in a chunky pixel font, other text in a clean readable
pixel font. Warm, cute, Malaysian (kopitiam, shophouses, hawker food) but no real brand logos and no real app logos.
```
